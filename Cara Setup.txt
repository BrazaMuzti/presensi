
## 🚀 Cara Setup

### 1. Buat Google Spreadsheet

Buat spreadsheet dengan 5 sheet:

| Sheet | Kolom |
|-------|-------|
| **Siswa** | NIS, Nama, Kelas, JK, Tanggal Lahir, Agama, Ayah, Ibu, HP, Alamat, Keterangan, Password, Ekstra |
| **Guru** | Username, Kelas, Password, Jabatan |
| **Absensi** | NIS, Nama, Kelas, Tanggal, Waktu, Status, Keterangan, Lokasi |
| **Jadwal** | ID, Mapel, JamDatang, JamSelesai, Kelas |
| **Libur** | Tanggal, Keterangan |

### 2. Deploy Google Apps Script

1. Buka spreadsheet → Extensions → Apps Script
2. Copy kode dari `appscript/Code.gs`
3. Ganti `YOUR_SPREADSHEET_ID_HERE` dengan ID spreadsheet
4. Deploy → New Deployment → Web App
   - Execute as: **Me**
   - Who has access: **Anyone** (atau Anyone with link)
5. Copy URL deployment

### 3. Update Config

Buka `config/config.js` dan ganti:

```javascript
SPREADSHEET_ID: 'YOUR_SPREADSHEET_ID_HERE',
WEB_APP_URL: 'https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec'
